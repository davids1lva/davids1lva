# Portfólio David Silva

Versão pronta para publicar no GitHub Pages.

## Publicar

1. Abre o repositório no GitHub.
2. Escolhe **Add file → Upload files**.
3. Envia todos os ficheiros e a pasta `assets` deste pacote.
4. Confirma em **Commit changes**.
5. Em **Settings → Pages**, escolhe `main` e `/ (root)`, depois guarda.

O ficheiro `index.html` deve ficar na raiz do repositório, sem uma pasta adicional à volta.
